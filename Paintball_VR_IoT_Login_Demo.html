Acerca del proyecto

Modelo de Realidad Virtual e IoT para la simulación interactiva de Paintball en entornos controlados

El proyecto propone integrar un entorno virtual interactivo con tecnologías IoT para detectar y representar eventos de una partida de Paintball.

GodotEntorno virtual 3D y lógica de simulación.
ESP32 + sensoresAdquisición de eventos físicos en una etapa posterior.
Wi-Fi / MQTTTransmisión de eventos según la implementación.
PythonMonitoreo, procesamiento y registro.
Este HTML es un prototipo de presentación. No reemplaza la implementación real en Godot ni demuestra pruebas físicas con ESP32.
