Modelo de realidad virtual e IoT para la simulacion interactiva de paintball en entornos controlados

El proyecto integra un entorno virtual interactivo con tecnologias IoT para detectar y representar los eventos de una partida de paintball. Esta plataforma web actua como centro de control: autentica usuarios, administra el roster, ejecuta la simulacion de la partida y consolida la telemetria de eventos.

Componentes previstos

  • Godot - entorno virtual 3D y logica de simulacion.
  • ESP32 + sensores - adquisicion de eventos fisicos del marcador y los impactos.
  • Wi-Fi / MQTT - transporte de los eventos hacia la plataforma.
  • Python / Django - centro de control, autenticacion y registro de eventos.
  • Firebase Realtime Database - almacenamiento en tiempo real de usuarios, roster, partidas y eventos.

Alcance de esta version

Esta entrega implementa el centro de control web completo con arquitectura MVI. Los eventos se generan desde la propia plataforma (fuente web); la integracion fisica con ESP32 y Godot se conecta escribiendo en el mismo nodo events con las fuentes esp32, mqtt o godot.

nota El login se valida contra el nodo users de Realtime Database, no contra Firebase Authentication. Es adecuado para un entorno academico controlado.

Bloques

  • core - Store, Intent, Effect, Reducer, State y cliente REST de Firebase.
  • theme - tema Tokyo Night / Omarchy OS: tokens, layout y componentes.
  • accounts - autenticacion contra el nodo users.
  • telemetry - dominio compartido de eventos y sesiones.
  • dashboard - consolidacion del resumen del sistema.
  • simulation - maquina de estados de la partida.
  • players - roster sincronizado con players.
  • history - visor de telemetria con filtro por severidad.

Nodos

  • users/<usuario> - credenciales (hash PBKDF2) y rol.
  • players/<id> - roster con equipo, estado y estadisticas.
  • sessions/<match_id> - espejo del estado de cada partida.
  • events/<id> - telemetria: tipo, detalle, severidad, fuente y actor.
